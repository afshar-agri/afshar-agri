# افشار اگری (Afshar Agri)
> سامانه تخصصی توصیه کودی، تجویز سموم و مدیریت باغات پسته خوشه قرمز قزوین  
> **موسس:** مهندس علی افشار (دانشجوی دکتری کشاورزی)

---

## معرفی پروژه
وب‌اپلیکیشن **«افشار اگری»** یک پلتفرم علمی و مهندسی برای باغداران پسته دشت قزوین، بوئین‌زهرا و سراسر کشور است که با رویکرد داده‌محور، جایگزینی برای مصرف بی‌رویه کود و سموم شیمیایی سنتی فراهم می‌کند.

### امکانات سامانه:
1. **سامانه هوشمند توصیه کودی پسته:** محاسبه دقیق عناصر پرمصرف و کم‌مصرف (N, P, K, Ca, Mg, Zn, B) در مراحل فنولوژی (فروت‌ست، فندقی، پر شدن مغز، قبل از برداشت و چالکود زمستانه).
2. **تجویز سموم و مدیریت تلفیقی آفات (IPM):** راهنمای گام‌به‌گام مبارزه با پسیل پسته (شیره خشک)، پروانه چوبخوار، سن و سنک، گموز و آفتاب‌سوختگی، همراه با دوره کارنس (PHI) و گزینه‌های بیولوژیک و ارگانیک (صابون پالیزین، کائولین، روغن ولک).
3. **پرونده پسته خوشه قرمز قزوین:** بررسی ویژگی‌های اکوفیزیولوژیک، نیاز سرمایی (۷۰۰-۸۰۰ ساعت)، زمان گلدهی و حساسیت به حرارت تابستان.
4. **تحلیلگر سریع آزمایش آب و خاک:** ارزیابی شوری (ECe و ECw)، اسیدیته (pH)، نسبت جذب سدیم (SAR) و راهکارهای اصلاحی خاک‌های آهکی قزوین.
5. **گاه‌شمار ۱۲ ماهه باغبانی:** راهنمای تقویمی از فروردین تا اسفند برای آبیاری، محلول‌پاشی و هرس بهداشتی.
6. **صدور نسخه چاپی رسمی:** امکان صدور و پرینت نسخه A4 استاندارد همراه با مهر و امضای کارشناس.
7. **فرم مشاوره و ویزیت حضوری:** اتصال به واتساپ و ثبت در پایگاه داده محلی.

## نحوه استقرار روی GitHub Pages (مخصوص علی افشار)

این پروژه از قبل در `vite.config.ts` با `base: './'` تنظیم شده است، بنابراین بدون هیچ مشکلی روی GitHub Pages بارگذاری می‌شود.

### دستورات گیت برای ارسال به ریپازیتوری:

```bash
git init
git add .
git commit -m "Initial commit for Afshar Agri web application"
git branch -M main
git remote add origin https://github.com/aafshar268/afshar-agri.git
git push -u origin main
```

### فعال‌سازی خودکار در گیت‌هاب:
1. در صفحه ریپازیتوری در گیت‌هاب به مسیر **Settings** بروید.
2. از منوی چپ گزینه **Pages** را انتخاب کنید.
3. در بخش **Build and deployment** منوی کشویی Source را روی **GitHub Actions** قرار دهید.
4. فایل آماده `.github/workflows/deploy.yml` به صورت خودکار پروژه را بیلد و منتشر می‌کند.
5. آدرس سایت شما: `https://aafshar268.github.io/afshar-agri/`
