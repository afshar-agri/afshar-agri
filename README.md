## راهنمای رفع ارور «There isn't a GitHub Pages site here»

اگر این ارور را در آدرس گیت‌هاب پیجز مشاهده کردید، علت این است که گیت‌هاب هنوز این ریپازیتوری را در بخش Pages فعال نکرده است. برای حل فوری در ۳ گام:

### گام اول: مطمئن شوید ریپازیتوری Public است
در گیت‌هاب، سرویس GitHub Pages برای حساب‌های کاربری رایگان فقط روی ریپازیتوری‌های **Public** کار می‌کند. اگر ریپازیتوری شما Private است، در بخش **Settings > General > Danger Zone** آن را به **Public** تغییر دهید.

### گام دوم: ارسال کدها (Push)
کدهای پروژه در دو شاخه `main` (سورس‌کد کامل پروژه) و `gh-pages` (نسخه بیلد شده و آماده اجرا) کامیت شده‌اند. کافیست در ترمینال دستورات زیر را اجرا فرمایید:

```bash
git remote add origin https://github.com/aafshar268/afshar-agri.git
git push -u origin main
git push -u origin gh-pages
```

*(نکته: اگر نام کاربری شما در گیت‌هاب چیزی غیر از `aafshar268` است، آدرس بالا را با نام کاربری خودتان جایگزین کنید).*

### گام سوم: فعال‌سازی در منوی Settings گیت‌هاب
1. در ریپازیتوری خود وارد تب **Settings** شوید.
2. از ستون چپ روی **Pages** کلیک کنید.
3. در قسمت **Build and deployment > Branch**، شاخه را روی **gh-pages** و پوشه را روی **/ (root)** بگذارید و **Save** کنید.
4. ظرف ۱ الی ۲ دقیقه، وب‌سایت شما در آدرس زیر بدون هیچ خطایی لود خواهد شد:
   `https://aafshar268.github.io/afshar-agri/`

## امکانات سامانه:
- **توصیه کودی هوشمند:** بر اساس مراحل فنولوژی درخت پسته و بافت خاک قزوین
- **تجویز سموم و مدیریت آفات (IPM):** پسیل، پروانه چوبخوار، سن و سنک، گموز و آفتاب‌سوختگی
- **پرونده پسته خوشه قرمز قزوین:** بررسی جامع نیاز سرمایی، زمان گلدهی و حساسیت‌ها
- **آنالیزور سریع آب و خاک:** تفسیر بالینی EC و pH و SAR
- **تقویم سالانه باغبانی:** راهنمای ۱۲ ماهه عملیات باغداری
- **صدور نسخه چاپی با مهر و امضا:** امکان چاپ فوری در قطع استاندارد A4
- **درخواست مشاوره:** ارتباط مستقیم با مهندس علی افشار
